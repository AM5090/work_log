# 🛠️ Стек

## База данных

**PostgreSQL** - продуманная, популярная БД позволяющая легко и быстро создавать базы данных и таблицы, работает с большинством ORM (на проекте sequelize).

**Docker** - БД упакована в Docker и запускается через docker-compose, что позволяет быстро запустить БД на лубом хосте без предварительных настроек.

## Backend

**Nest.js** - позволяет быстро и удобно собрать приложение, контроллеры и сервисы для функционала. Легко и быстро настраивается, можно легко изменять настройки при необходимости. Востребованный инструмент.

**Sequelize** - популярная ORM система позволяющая удобно работать с различными БД, в том числе через TS.

## Frontend

**TanstackQuery** - позволяет удобно работать с запросами, имеет хороший функционал для кеширования, нет избыточного кода.

**Axios** - утилита для запросов к серверу по REST API, позволяет делать запросы без написания лишней логики.

**antd** - готовые компоненты для использования в приложении без лишней стилизации на предварительном этапе

**react-router-dom** - стандарт для роутинга в приложении

**vite** - современный и быстрый инструмент для сборки React приложений

# 🚀 Запуск приложения

## Быстрый запуск

#### Запуск БД через docker-compose файл

> docker-compose up -d

#### Запуск backend в режиме разработки

> npm run dev:backend

#### Запуск frontend в режиме разработки

> npm run dev:frontend

## Сборка и запуск

#### Сборка backend

> npm run build:backend

#### Сборка frontend

> npm run build:frontend

#### Запуск backend

> npm run start:prod

#### Запуск frontend

> npm run preview
